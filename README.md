# 🎂 Birthday Surprise - 生日惊喜互动网站

一个创意十足的生日惊喜互动网站，通过摄像头识别人物动作和手势，层层递进展现惊喜。使用 TensorFlow.js、MediaPipe 和 Three.js 等前沿技术打造。

## ✨ 功能特点

### 第一层：星空粒子开场 ⭐
- 黑色背景中，成千上万的粒子缓缓飘动形成星空
- 粒子会跟随摄像头捕捉到的人脸移动
- 文字缓缓浮现："有个人想对你说..."
- **挥手动作** → 星空粒子汇聚成一颗心形 ❤️

### 第二层：照片粒子墙 📸
- 心形粒子爆炸散开，每个粒子变成照片碎片
- 照片像萤火虫一样漂浮在屏幕中
- **张开双臂** → 照片飞向用户，在身体周围环绕旋转
- **双手合拢** → 照片汇聚成一张完整的合照

### 第三层：时间轴隧道 ⏰
- 进入一个3D时光隧道，两侧是重要时刻照片
- 走近摄像头 = 前进，后退 = 回溯
- 每张照片配上日期和一句话
- **停留3秒看某张照片** → 照片放大，显示详细信息

### 第四层：烟花祝福雨 🎆
- 做出"比心"手势触发
- 屏幕绽放绚丽烟花，烟花落下变成祝福文字
- **拍手** → 触发更多烟花
- **双手向上举** → 烟花大爆发

### 第五层：许愿蜡烛 🕯️
- 静止不动5秒触发
- 画面变暗，出现3D生日蛋糕和跳动的蜡烛
- **检测到吹气动作**（嘴部张开+向前）→ 蜡烛一根根熄灭
- 全部熄灭后，烟雾升腾，变成文字："生日快乐，我爱你"

### 第六层：告白彩蛋 💝
- 所有蜡烛熄灭后触发
- 背景音乐响起
- 粒子形成名字+爱心动画
- 屏幕下雪/落花瓣，照片墙再次浮现
- 最后一行字："往后余生，都是你"

## 🚀 快速开始

### 准备工作

1. 克隆或下载此项目到本地
2. 准备好你想要展示的照片

### 本地运行

由于浏览器安全限制，需要通过 HTTP 服务器运行此项目：

**方法一：使用 Python (推荐)**
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

**方法二：使用 Node.js**
```bash
# 安装 http-server
npm install -g http-server

# 运行服务器
http-server -p 8000
```

**方法三：使用 VS Code Live Server 插件**
- 安装 "Live Server" 插件
- 右键点击 `index.html` 选择 "Open with Live Server"

然后在浏览器中访问 `http://localhost:8000`

### 重要提示

- **必须允许摄像头访问权限**，否则无法体验完整功能
- 建议使用 Chrome 或 Edge 浏览器以获得最佳体验
- 确保光线充足，摄像头能清晰捕捉到人脸和手势
- 首次加载可能需要一些时间来下载 AI 模型

## 🎨 自定义配置

### 1. 添加自己的照片

将照片放入 `assets/photos/` 目录，命名为：
- `photo1.jpg`
- `photo2.jpg`
- `photo3.jpg`
- `photo4.jpg`
- `photo5.jpg`

可以添加更多照片，只需在 `js/scenes/photowall.js` 中更新照片列表。

### 2. 修改时间轴内容

编辑 `js/scenes/timeline.js` 中的 `timelineData` 数组：

```javascript
timelineData: [
    { date: '2020-01-15', text: '我们第一次相遇，你的笑容让我心动' },
    { date: '2020-03-20', text: '第一次牵手，感觉世界都变得温暖' },
    // 添加更多回忆...
]
```

### 3. 修改祝福文字

编辑 `js/scenes/fireworks.js` 中的 `blessings` 数组：

```javascript
blessings: [
    '生日快乐', '永远幸福', '心想事成', 
    // 添加更多祝福语...
]
```

### 4. 修改名字

编辑 `js/scenes/finale.js` 中的 `showName()` 方法：

```javascript
nameElement.textContent = '亲爱的宝贝'; // 改成你想要的名字
```

### 5. 调整蜡烛数量

编辑 `js/scenes/candles.js` 中的 `candleCount` 变量：

```javascript
const candleCount = 5; // 改成对应的年龄
```

### 6. 添加背景音乐

1. 将音乐文件放入 `assets/audio/` 目录
2. 在 `index.html` 中添加音频元素：

```html
<audio id="background-music" loop>
    <source src="assets/audio/your-song.mp3" type="audio/mpeg">
</audio>
```

## 🎮 调试功能

开发和测试时可以使用以下快捷键：

- **数字键 1-6**：直接跳转到对应场景
- **N 键**：下一个场景
- **R 键**：重新开始

调试面板会显示在左下角，显示当前检测到的手势和状态信息。

## 🛠️ 技术栈

- **前端框架**：原生 JavaScript (ES6+)
- **AI 模型**：
  - TensorFlow.js - 机器学习框架
  - MediaPipe Hands - 手势识别
  - PoseNet - 姿态检测
  - FaceMesh - 面部识别
- **图形渲染**：
  - Canvas API - 2D 粒子效果
  - Three.js - 3D 场景
- **特效库**：
  - canvas-confetti - 烟花效果

## 🎯 使用建议

1. **测试环境**：在正式使用前，先自己测试一遍流程，熟悉各个手势
2. **光线条件**：确保环境光线充足，有助于摄像头识别
3. **距离控制**：站在距离摄像头约1-2米的位置效果最佳
4. **手势幅度**：做手势时幅度要大一些，更容易被识别
5. **耐心等待**：某些场景需要保持特定姿势几秒钟，请耐心等待

## ⚠️ 常见问题

### Q: 摄像头无法访问？
A: 检查浏览器权限设置，确保允许该网站访问摄像头。如果使用 HTTPS，某些浏览器可能会自动允许。

### Q: 手势识别不准确？
A: 确保光线充足，手势幅度足够大，并且站在摄像头前约1-2米的位置。

### Q: 加载时间过长？
A: AI 模型文件较大，首次加载需要下载。请耐心等待，后续访问会使用缓存。

### Q: 某些场景无法触发？
A: 尝试使用键盘快捷键（1-6）直接跳转到场景进行测试。检查控制台是否有错误信息。

### Q: 在手机上无法使用？
A: 手机性能可能不足以流畅运行所有 AI 模型。建议在桌面电脑或高性能设备上使用。

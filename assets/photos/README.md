# Photos Directory

## Current Files

The current files (photo1.jpg - photo5.jpg) are **placeholder SVG files** saved with .jpg extension for demonstration purposes only.

## For Production Use

**Please replace these files with your actual photos:**

1. Delete the placeholder files
2. Add your own photos in JPG or PNG format
3. Name them: `photo1.jpg`, `photo2.jpg`, `photo3.jpg`, `photo4.jpg`, `photo5.jpg`

## Recommended Photo Specifications

- **Format**: JPG or PNG
- **Resolution**: 1920x1080 or smaller
- **File Size**: Under 2MB per photo
- **Aspect Ratio**: 4:3 or 16:9

## Adding More Photos

To add more than 5 photos, edit `js/scenes/photowall.js` and update the `photos` array.

Example:
```javascript
this.photos = [
    'assets/photos/photo1.jpg',
    'assets/photos/photo2.jpg',
    'assets/photos/photo3.jpg',
    'assets/photos/photo4.jpg',
    'assets/photos/photo5.jpg',
    'assets/photos/photo6.jpg', // Add more here
];
```
